# Maintainers

OpSecMap is currently maintained by `onyks` ([@onyks-it](https://github.com/onyks-it)).
The maintainer reviews changes to the Rust model, documentation, and repository
workflows. This is a small project in early development; there is no separate
release team or published package to maintain yet.

Contributors are welcome through [issues and pull requests](CONTRIBUTING.md).
The repository's CI and DCO workflows describe automated checks for pull
requests. Security concerns should be sent privately using the instructions in
[SECURITY.md](SECURITY.md).

This file does not describe private credentials, repository access settings,
or response-time commitments. Those may change independently of the source tree.
